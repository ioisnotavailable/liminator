# Limine Bootloader İçin Kurulum Scripti

Saf Arch Linux kurulumuda bootloader tercihini Limine Bootloader'dan yana yapmışsanız eğer birkaç saniye içinde Limine Bootlıader kurmanızı sağlayacak scripttir.

## Dikkat Edilmesi Gerekenler
- Script Türkçe hazırlanmıştır.

## Gereklilikler
- limine
- efibootmgr
- blkid

## Kurulumu
Repoyu klonladıktan sonra,

>`./install.sh` 

komutu ile kurulum başlar.
